\begin{definition}
	A \Petrinet{} $\Omega$ is a directed graph $(V, E)$ with vertices $V=V_X \cup
		V_Z$ where $V_X$ are state vertices and $V_Z$ are transition
	vertices.
\end{definition}

\begin{definition}
	Let $E(v) = \edgesIn{}(v) \cup \edgesOut{}(v)$, and for all $e = (v, v') \in E$,
        $e \in \edgesOut{}(v)$ and  $e \in \edgesIn{}(v')$.
        We define the \emph{parent} and \emph{child} of an edge, $\parent( (v, v') ) = v$ and $\child( (v, v') ) = v'$.
        We define the parents (descendents) of a vertex, $\parents(v)$ ($\children(v)$) as the set of parents (children) of the edges in and out, respectively. 
        Further, % for all $(v, v') \in E$,
        if $v \in
V_X$ then $v' \in V_Z$ and if $v \in V_Z$, then $v' \in V_X$.
\end{definition}

\begin{example}
	The SIR model defines $\Omega$ by:
	\begin{eqnarray*}
		V_X &=& \{v_{S}, v_{I}, v_{R}\}\\
		V_Z &=& \{ \vinf, \vrec\}\\
		E &=& \{ (v_{S}, \vinf),(v_{I}, \vinf{}), (\vinf{}, v_{I}), (\vinf{}, v_{I}),  (v_{I}, \vrec{}), (\vrec{}, v_{R})\}
	\end{eqnarray*}
        The SIR model is depicted in Figure \ref{fig:sir_model}.
\end{example}

We develop the semantics by associating state variables to each
state vertex of the graph, such as $S$, $I$, and $R$. The transitions and their
associated rates encode the ODE system that models how the state changes.  For
example, the initial state vector ${\bf x}(0) = (S(0), I(0), R(0))$ assigns a value to each state
variable.

These state variables
assume homogenous subpopulations that become infected and recover at the same rates.
Stratification and abstraction operate on the model to either partition or
aggregate the subpopulations associated with each state variable to better
capture these rates. For example, we may distinguish subpopulations
with different vaccination status, gender, or age, and there will be a different
value of $S$, $I$, and $R$ for each.

We facilitate this by extending the state description with discrete variables.
Each assignment to the discrete variables describes a different subpopulation.
For example, $(I, \{(vac=T,
	gender=M, age=child)\})$ and $(I, \{(vac=T, gender=F, age=child)\})$ refer to
the number of infected, vaccinated male children and female children, respectively.  We could
capture fully-specified discrete states by indexing the state variables to give, for example,
$I_{TMC}$, and $I_{TFC}$.
However, later when construct abstractions, it will be more convenient to refer to \emph{sets} of assignments to the discrete variables, of the form $(x, g)$, where $g$ is a \emph{set} of assignments to the discrete variables.
For example, if gender is not relevant to infection
rates, we could define the set of susceptible, vaccinated children as $(S, g)$, where $g=
	\{(vac=T, gender=M, age=child), (vac=T, gender=F, age=child)\}$.

\begin{definition}
	The ODE semantics $\Theta$ of the \Petrinet{} $\Omega$ defines a tuple $(P, D, X,
		Z, {\cal P}, {\cal X}, {\cal D}, {\cal I}, {\cal Z}, {\cal R})$ where
	\begin{itemize}
		\item $P$ is a set of parameters;
		\item $D$ is a set of discrete state variables, and for each $d \in
			      D$, $dom(d)$ is a finite set of values;
		\item $X$ is a set of continuous state variables;
		\item $Z$ is a set of transitions;
		\item ${\cal P}: P \rightarrow \reals \cup (\reals \times \reals)$ assigns
		      parameters to a real number, or a pair of real numbers defining an
		      interval;
		\item ${\cal X}: V_X  \rightarrow X$ assigns a
		      continuous variable to each state
		      vertex;
		\item ${\cal D}: V_X \rightarrow 2^{G}$ maps a group description $g
			      \subseteq G$ where $G=dom(d_1) \times \ldots
			      \times dom(d_{|D|})$
		      to each $v \in V_X$.
		\item ${\cal I}: X \rightarrow \reals$ assigns the initial value of
		      continuous state variables to a real number;
		\item ${\cal Z}: V_Z  \rightarrow Z$ assigns transitions to transition
		      vertices; and
		\item ${\cal R}: {\bf P} \times {\bf X} \times Z \rightarrow \reals$
		      defines the rate of each transition  $z \in Z$ in terms of the set of
		      parameter vectors ${\bf P}$ and state vectors ${\bf X}$. Each
		      component of the state vector ${\bf x}$ defines the value some $(x, g)$
		      mapped to a state vertex,
	\end{itemize}

	The semantics associates a pair $({\cal X}(v),{\cal D}(v)) = (x, g)$ with each vertex $v \in V_X$ where $x
		\in X$ and $g \subseteq G$.  We assume that the mapping of state variables
	to vertices is complete, so that for each $x \in X$ there is a
	$v \in V_X$ where ${\cal X}(v) = x$.  The set of vertices $V(x)=\{v \in V_X | {\cal
		X}(v) = x\}$ associated with $x$ also partitions the groups, so
	that $G = \bigcup_{v\in V(x)}{\cal D}(v)$ and for each $v_1, v_2 \in V(x)$,
	${\cal D}(v_1)\cap{\cal D}(v_2) = \emptyset$.
	The elements of the \Petrinet{} $\Omega$ and semantics $\Theta$ define the
	partial derivative $\frac{d {\bf x}}{dt}$, so that for each $(x, g)$ which maps to
	a vertex $v$:

	\begin{equation}\label{eqn:flow}
		\frac{d(x, g)}{dt} = \sum_{(v_z, v) \in E} {\cal R}({\bf p}, {\bf x}, z) - \sum_{(v, v_z)\in E}  {\cal R}({\bf p}, {\bf x}, z)
	\end{equation}

\begin{definition}
	A balanced-flow \Petrinet{} preserves the flow through each transition by requiring that its inflows and outflows balance: $|\edgesIn{}(v_z)| = |\edgesOut{}(v_z)|$ for each $v_z \in V_Z$.
\end{definition}

\begin{definition}
Each balanced-flow \Petrinet{} transition $z$ defines a set of state transitions

\begin{equation*}
  \begin{split}
    st(z) = \{((x, g), z, (x', g')) | & (v, z) \in \edgesIn{}(z), \\
                                      & ({\cal X}(v),{\cal D}(v)) = (x, g),  \\
                                      & (z, v') \in \edgesOut{}(z), \\
                                      & ({\cal X}(v'),{\cal D}(v')) = (x', g')\}
  \end{split}
\end{equation*}

each of whose elements matches an input state with exactly one output state, and vice versa.
\end{definition}

\begin{definition}
	An independent-transition \Petrinet{} requires that for each transition, there
	is exactly one $((x, g), z,
        (x', g')) \in st(z)$ where $(x, S)\not= (x', S')$.

\end{definition}

A balanced-flow, independent-transition \Petrinet{} permits only a single state
change with each transition.  That is, all flows out of a transition node either return to one of its input nodes or flow into a single output node. 
The other edges into the state transitions involve no net flow; they simply serve to identify other variables that influence the rate of the state change.

Using the partial derivatives defined by the \Petrinet{} graph and semantics, we
can define the state vector at given time $t+dt$ with the forward Euler method
as:

\begin{eqnarray*}
	\frac{d {\bf x}}{dt} &=& \nabla_{\Omega, \Theta}({\bf p},{\bf x}, t)\\
	\frac{{\bf x}(t+dt)-{\bf x}(t)}{dt} &=& \nabla_{\Omega, \Theta}({\bf p},{\bf x},
	t)\\
	{\bf x}(t+dt)&=& \nabla_{\Omega, \Theta}({\bf p},{\bf x}, t)dt+ {\bf x}(t)
\end{eqnarray*}
